# Landscape signatures in 3D

**[Open the dashboard](https://rashiedomar.github.io/landscape-explorer-3d/)**

An interactive landscape assessment of Angkor, Srei Santhor, Sukhothai and Prambanan. Explore 2025 seasonal satellite imagery and open water, vegetation change, 2021 land cover, terrain, modelled flow paths and OpenStreetMap temple and heritage records.

The map includes guided tours, adjustable terrain exaggeration, a height-above-drainage threshold and point inspection. Sources, methods and reading notes are available within the dashboard.

Data sources include Copernicus Sentinel-2 and GLO-30 DEM, ESA WorldCover, JRC Global Surface Water and OpenStreetMap. Built with MapLibre GL JS; basemap © OpenStreetMap contributors.

This is an exploratory assessment. Terrain-derived layers are unvalidated models; seasonal observations and mapped temple names do not establish archaeological dates or agricultural functions.
